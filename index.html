02 / 规则

如何游玩

霓虹转轮使用一条中间中奖线，规则简单明确。

  1. 选择投注额。可选 1、5 或 25 积分。投注额会立即从余额中扣除。
  2. 旋转转轴。点击「旋转」按钮，或在页面任意处按空格键。三个转轴独立停止。
  3. 匹配符号。若中奖线上出现三个相同符号，按赔率表获得对应倍数积分；若出现恰好两个相同符号，获得 1 倍积分（两个樱桃为 2 倍）。
  4. 继续或补充。余额不足时点击「补充积分」，系统会免费重置为 1,000 积分。虚拟积分不可兑换任何真实财物。

04 / 问答

常见问题

关于霓虹转轮的性质、公平性与使用方式的直接回答。

霓虹转轮是真实的赌博游戏吗？

不是。霓虹转轮只使用本地虚拟积分，不能充值、不能提现，也不涉及任何真实货币或财物。它是一款纯粹的浏览器娱乐游戏，面向成年玩家。

玩霓虹转轮需要注册或下载吗？

不需要。打开网页即可游玩，无需账号、无需下载安装。积分余额与统计保存在当前浏览器的本地存储中，清除浏览器数据会重置进度。

95.78% 的理论回报率是什么意思？

理论回报率（RTP）指长期大量旋转中，返还积分占投注积分的期望比例。霓虹转轮的精确值为 1655/1728，约 95.78%。单次结果仍然随机，短局结果可能高于或低于该值。

游戏结果是如何生成的？

游戏使用浏览器 Web Crypto API 的加密安全随机数，并通过拒绝采样避免取模偏差。每条转轴有 12 个等概率位置，三个转轴独立抽取，因此实际分布与公布的赔率表一致。

可以在手机或键盘上游玩吗？

可以。页面采用响应式布局，适配手机、平板与桌面。所有按钮均为原生控件，可用 Tab 聚焦、空格或回车触发；旋转结果通过无障碍实时区域朗读。
